# AI Tender Hub — Парсер тендеров для анализа импорта

Инструмент собирает тендеры с **goszakup.gov.kz** (госзакупки РК) и
**zakup.sk.kz** (Самрук-Казына), складывает их в SQLite и выдаёт топ
импортных товаров — кандидатов на локализацию производства в Казахстане.

## Логика «кандидата на локализацию»

Импортным считается лот, для которого выполнено **любое** из условий:
1. `country_origin` лота указан и не равен `KZ`.
2. По коду КТРУ нет ни одного действующего сертификата СТ-KZ в реестре
   индустриальных сертификатов (т.е. казахстанского производителя нет
   в принципе).

Кандидаты ранжируются по суммарному объёму закупок в KZT, числу
заказчиков и числу тендеров — это даёт оценку рыночной ёмкости
для будущего локального завода.

## Установка

```bash
cd parser
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Для goszakup GraphQL нужен бесплатный Bearer-токен — получить в
личном кабинете на goszakup.gov.kz, затем:

```bash
export GOSZAKUP_TOKEN="..."
```

## Использование

```bash
# 1. Загрузить тендеры за последние 30 дней из обоих источников
python -m tender_parser fetch --source both --days 30

# 2. Обновить реестр СТ-KZ и проставить флаги локализации
python -m tender_parser refresh-stkz

# 3. Посмотреть топ-30 кандидатов на локализацию
python -m tender_parser candidates --limit 30 --min-kzt 100000000

# 4. Выгрузить в CSV для презентации/аналитики
python -m tender_parser export --what candidates --out exports/candidates.csv

# 5. Состояние БД
python -m tender_parser info
```

## Схема БД

- `tenders` — закупка верхнего уровня (объявление)
- `lots` — лот с КТРУ-кодом, страной происхождения, суммой, победителем
- `suppliers` — БИН/наименование победителей
- `ktru` — справочник КТРУ
- `st_kz_certificates` — реестр индустриальных сертификатов СТ-KZ

Уникальность тендеров: `(source, external_id)`. Повторный `fetch`
делает UPSERT — историю можно накапливать инкрементально.

## Ограничения

- Структура Samruk API не имеет публичной спецификации — маппинг полей
  основан на наблюдаемых ответах и защищён `.get()`. При изменении
  формата правьте `sources/samruk.py::_map_announce/_map_lot`.
- Эндпоинт реестра СТ-KZ может отдавать данные в произвольном формате;
  принимается `list` или объект с ключом `items`/`data`. При иной
  структуре переопределите `ST_KZ_REGISTRY` или адаптируйте
  `ktru.py::load_st_kz_registry`.
- Парсер не обходит каптчу и не имитирует пользователя — только
  публичные API.
