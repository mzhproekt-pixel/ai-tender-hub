# Mail CRM — анализ переписки Mail.ru

Система превращает историю писем с Mail.ru в структурированную CRM-базу
с аналитикой по контактам и тредам. Работает локально, данные хранятся
в одном файле SQLite (`mail_crm.db`).

## Что получится на выходе

`mail_crm_report.xlsx` с листами:

1. **Контакты** — все, с кем шла переписка, с компанией/сферой/типом отношений.
2. **Треды активные** — переписки за последние 14 дней.
3. **Висяки — мне надо ответить** — где последнее письмо от собеседника.
4. **Висяки — ждём от них** — кандидаты на follow-up (≥ 3 дней без ответа).
5. **Замороженные** — старые сделки (offer/negotiation), по которым >14 дней тишина.
6. **Сводка** — общая статистика и топ-10 контактов.

## Шаг 1. Получить пароль приложения Mail.ru

Обычный пароль от почты для IMAP не подходит — Mail.ru требует **пароль приложения**.

1. Откройте https://account.mail.ru/user/2-step-auth/ и при необходимости
   включите **двухфакторную аутентификацию** (без неё пароли приложений недоступны).
2. Перейдите в раздел **«Пароли для внешних приложений»**
   (прямая ссылка: https://account.mail.ru/user/2-step-auth/passwords).
3. Нажмите **«Добавить»**, придумайте название (например, *Mail CRM*) и
   подтвердите действие.
4. Mail.ru покажет 16-символьный пароль **один раз** — скопируйте его сразу.
   Этот пароль и есть `MAILRU_APP_PASSWORD`.

## Шаг 2. Получить ключ Anthropic

1. Зарегистрируйтесь / войдите на https://console.anthropic.com.
2. В разделе **API Keys** создайте новый ключ.
3. Скопируйте значение `sk-ant-...` — это `ANTHROPIC_API_KEY`.

## Шаг 3. Установить зависимости

Понадобится Python 3.10 и выше.

```bash
cd mail_crm
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 4. Прописать настройки

Скопируйте `.env.example` в `.env` и подставьте значения. Затем загрузите
их в окружение перед запуском:

```bash
cp .env.example .env
# отредактируйте .env, потом:
export $(grep -v '^#' .env | xargs)
```

В Windows проще задавать переменные перед командой:

```bat
set MAILRU_LOGIN=info@casc.kz
set MAILRU_APP_PASSWORD=...
set ANTHROPIC_API_KEY=sk-ant-...
set START_DATE=2026-04-13
```

## Шаг 5. Запуск (поэтапно)

Скрипты независимы и **идемпотентны** — повторный запуск не дублирует данные.

### 5.1. Выгрузка писем

```bash
python fetch.py
```

Подключается к `imap.mail.ru:993`, забирает письма из **INBOX** и
**Отправленные** начиная с `START_DATE`. Прогресс печатается каждые 50 писем.
По итогу в БД появляются строки в `messages`.

> Проверить сырые данные удобно бесплатным **DB Browser for SQLite**:
> откройте файл `mail_crm.db` и пройдитесь по таблицам.

### 5.2. Обогащение через Claude

```bash
python analyze.py
```

Для каждого ещё не проанализированного письма вызывает `claude-opus-4-7`,
получает summary, категорию, упомянутые проекты и обязательства,
параллельно дополняет таблицу `contacts` (имена, компании, сферы, счётчики).

Скрипт можно **прерывать (Ctrl+C) и запускать снова** — он догонит
необработанные письма. Между запросами пауза 0.5 секунды.

### 5.3. Построение тредов и аналитики

```bash
python match.py
```

Склеивает письма в треды по `In-Reply-To` / `References`, считает направление
последнего письма, дни с последней активности и проставляет `relation_type`
у контактов (`lead`, `client`, `partner`, `contact`).

### 5.4. Отчёт в Excel

```bash
python report.py
```

Создаёт `mail_crm_report.xlsx` рядом со скриптами.

## Как читать отчёт

- **«Висяки — мне надо ответить»** — открыть в первую очередь, отсортирован
  по «сколько дней висит».
- **«Висяки — ждём от них»** — здесь готовый список тех, кому стоит написать
  follow-up.
- **«Замороженные»** — потенциально упущенные сделки. Имеет смысл вернуться
  и реанимировать.
- **«Контакты»** — общая база, можно фильтровать по «Тип»: `lead`,
  `client`, `partner`.

## FAQ

**Скрипт упал на одном письме — что делать?**
Ничего страшного: ошибка попадёт в `errors.log`, остальные письма
обработаются. Перезапустите скрипт, он догонит необработанное.

**Как изменить дату, с которой тянуть письма?**
Поменяйте `START_DATE` в окружении и запустите `fetch.py` ещё раз.
Старые письма не задвоятся (стоит уникальный индекс на `Message-ID`).

**Можно использовать другой почтовый ящик Mail.ru?**
Да — поменяйте `MAILRU_LOGIN` / `MAILRU_APP_PASSWORD`. Удалите или
переименуйте `mail_crm.db`, если хотите начать с чистого листа.

**Сколько стоит Claude?**
Цена зависит от объёма писем. Для модели `claude-opus-4-7` см. актуальный
прайс на https://www.anthropic.com/pricing. Ориентир: 1 письмо ≈ 1 запрос,
обрезанный до 8000 символов тела.
